# Самостійна робота №2
### __Тема:__ Перевантаження конструкторів: приклади та сценарії.

# __Хід роботи:__
Було створено клас Product для представлення товарів інтернет-магазину. У класі реалізовано п’ять приватних полів та відповідні read-only властивості. Створено три перевантажені конструктори: основний, скорочений із використанням this(...) та конструктор копіювання. Також перевизначено метод ToString() для зручного виведення повної інформації про товар. У методі Main() продемонстровано створення товарів за допомогою всіх трьох конструкторів та виведено їхні дані в консоль.
