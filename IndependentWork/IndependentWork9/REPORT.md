# Частина 1: Аналіз використання у відкритих проектах

### Приклад 1. Dictionary

- Проєкт: .NET Runtime (Microsoft).
- Файл: Dictionary.cs.
- Посилання: https://github.com/dotnet/runtime/blob/main/src/libraries/System.Private.CoreLib/src/System/Collections/Generic/Dictionary.cs
- Контекст: зберігання даних у форматі «ключ - значення» та швидкий пошук елементів за ключем.
- Чому Dictionary: дозволяє швидко отримувати потрібне значення за унікальним ключем, на відміну від List, де потрібно послідовно переглядати елементи.
- Складність: додавання, пошук за ключем і видалення — O(1) у середньому, O(n) у найгіршому випадку; пошук за значенням — O(n).
- Особливі вимоги: підтримує IEqualityComparer&lt;TKey> для налаштування порівняння ключів. Ключі мають бути унікальними та не можуть бути null.

### Приклад 2. HashSet&lt;T>

- Проєкт: .NET Runtime (Microsoft).
- Файл: HashSet.cs.
- Посилання: https://github.com/dotnet/runtime/blob/main/src/libraries/System.Private.CoreLib/src/System/Collections/Generic/HashSet.cs
- Контекст: зберігання унікальних елементів і перевірка наявності певного елемента в колекції.
- Чому HashSet: автоматично запобігає дублюванню та забезпечує швидкий пошук елементів. На відміну від List, не потрібно послідовно переглядати всі елементи.
- Складність: додавання, пошук і видалення — O(1) у середньому, O(n) у найгіршому випадку.
- Особливі вимоги: підтримує IEqualityComparer<T>, який дозволяє налаштовувати порівняння елементів.

### Приклад 3. Dictionary&lt;TKey, TValue> та HashSet&lt;T>

- Проєкт: Entity Framework 6.
- Файл: EntityEntry.cs.
- Посилання: https://github.com/dotnet/ef6/blob/main/src/EntityFramework/Core/Objects/EntityEntry.cs
- Контекст: відстеження зв'язків між об'єктами під час роботи з базою даних.
- Чому Dictionary та HashSet: Dictionary зберігає зв'язки між об'єктами за ключами, а HashSet містить унікальні об'єкти, пов'язані з певним зв'язком. Їх спільне використання дозволяє швидко знаходити зв'язки та уникати повторень.
- Складність: пошук і додавання елементів у Dictionary та HashSet — O(1) у середньому, O(n) у найгіршому випадку.
- Особливі вимоги: для коректної роботи колекцій важливі методи Equals() і GetHashCode(), які визначають рівність об'єктів та їхні хеш-коди. Використовується стандартне порівняння елементів.

## Частина 2:

### 1. FileMetadataCache

Створено клас для зберігання метаданих файлів за унікальними ключами. Використовується `Dictionary<string, FileMetadata>`. Реалізовано додавання, отримання, видалення та перевірку наявності файлів.

### 2. TagManager

Створено клас для керування тегами статей. Використовується `Dictionary<string, HashSet<string>>`, де кожній статті відповідає множина унікальних тегів. Реалізовано додавання, видалення, пошук спільних тегів і отримання всіх унікальних тегів. Використано операції `UnionWith`, `IntersectWith` та `ExceptWith`.

### 3. SearchIndex

Створено простий пошуковий індекс на основі `Dictionary<string, HashSet<int>>`. Кожному слову відповідає множина ідентифікаторів документів, у яких воно зустрічається. Реалізовано додавання документів, пошук за одним словом і пошук документів, що містять усі задані слова. Для пошуку використовується `IntersectWith`.

## Частина 3:

| Операція             | List<T>                             | Dictionary<TKey, TValue>             | HashSet<T>                          |
| -------------------- | ----------------------------------- | ------------------------------------ | ----------------------------------- |
| Коли використовувати | Для впорядкованого списку елементів | Для зберігання пар «ключ - значення» | Для зберігання унікальних елементів |
| Додавання            | O(1) амортизовано                   | O(1) у середньому                    | O(1) у середньому                   |
| Пошук за значенням   | O(n)                                | O(n)                                 | O(1) у середньому                   |
| Пошук за ключем      | N/A                                 | O(1) у середньому                    | N/A                                 |
| Видалення            | O(n)                                | O(1) у середньому                    | O(1) у середньому                   |
| Перевірка наявності  | O(n)                                | O(1) у середньому                    | O(1) у середньому                   |

## Висновок

Під час виконання самостійної роботи було досліджено використання Dictionary&lt;TKey, TValue> та HashSet&lt;T> у .NET, а також створено три практичні класи: кеш метаданих файлів, менеджер тегів і пошуковий індекс. Було з'ясовано, що Dictionary зручний для пошуку за ключем, а HashSet — для зберігання унікальних елементів і виконання операцій над множинами. Також закріплено розуміння складності операцій та важливості правильного порівняння об'єктів через Equals() і GetHashCode().
